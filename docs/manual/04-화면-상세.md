# 4부. 화면별 상세

[← 목차](./기능-설명서.md)

화면 컴포넌트 경로는 모두 `apps/web/src/app/features/` 아래에 있다. 공통 패턴: 모든
화면의 에러 메시지는 `e?.error?.message ?? 기본문구` 형태로 표시되며, 이는 백엔드가
던지는 `{code, message}` payload와 그대로 맞물린다.

## 4.1 마스터데이터

### 카테고리 트리 (`master-data/pages/category-tree/category-tree.page.ts`)

| 항목 | 내용 |
|---|---|
| 화면 구성 | 들여쓰기(depth×24px)된 평면 리스트, 행마다 `+`(하위 추가)/연필(이름변경)/원형-X(비활성화) |
| 필수 입력 | 이름(빈 값이면 알럿이 닫히지 않음) |
| 검증 규칙 | 3단계 초과 생성 시 `E4105` |
| 저장 후 결과 | 트리에 즉시 반영. 비활성화는 확인 알럿 후 즉시 실행, 별도 성공 메시지 없음 |

### 마스터데이터 메뉴 (`master-data/pages/master-data-menu/master-data-menu.page.ts`)

거래처 관리 / 품목 관리 / 카테고리 관리 / 운송 단가표 / 엑셀 일괄 등록 5개 메뉴로만
구성된 라우팅 허브. API 호출 없음.

### 거래처 등록/수정 (`master-data/pages/partner-form/partner-form.page.ts`)

| 항목 | 내용 |
|---|---|
| 화면 구성 | 업체명, 사업자등록번호, 대표자/업태/종목/주소/담당자/연락처/이메일, 기본 운송요율 + **적용 시작일**(`partner-form.page.ts:43`), 요율 이력 목록(`:75`), (신규만) 보관계약 블록 |
| 필수 입력 | 업체명. 신규 등록 시 보관계약(유형 + 유형별 필드 + 시작일) |
| 검증 규칙 | 이름 누락 → "필수 항목을 입력하세요". `PALLET_DAILY`인데 단가 없음 → "파렛트 단가는 필수입니다". `AREA_*`인데 면적/단가 없음 → "면적과 단가는 필수입니다". 사업자등록번호는 10자리 체크섬 검증(3.8절). 기본 운송요율의 적용 시작일이 현재 열린 이력의 시작일 이하면 `E4113`(3.0절) |
| 저장 후 결과 | `/master-data/partners` 목록으로 이동 |
| 제약 | 수정 화면에는 보관계약 입력란이 없음(등록 후 수정 불가). 코드 필드는 신규는 입력 가능(비우면 자동 채번), 수정 시엔 읽기전용. 적용 시작일을 비우면 오늘 날짜가 기본값 |
| 알려진 트레이드오프 | 거래처 상세 조회 전용 API가 없어(`GET /master-data/partners/:id` 부재), 목록 화면에서 `router.navigate(..., {state:{partner}})`로 넘긴 데이터에만 의존한다. URL 직접 진입/새로고침 시 "거래처 정보를 불러올 수 없습니다. 목록에서 다시 선택해주세요."가 뜬다 |

## 4.4 거래처 포털 (PARTNER_COORDINATOR)

### 포털 홈 (`partner-portal/pages/portal-home/portal-home.page.ts`)

이번 달 운송 건수 + 총 금액을 보여준다. 로그인 계정에 `partnerId`가 없으면
"거래처 정보가 없습니다"만 표시하고 API를 호출하지 않는다. `getStatement`는 정산
자체가 없으면 그냥 0건을 반환하므로("마감 전"과 "실적 없음"을 구분하지 않음), 이번
달이 아직 마감되지 않은 경우와 실제로 거래가 없는 경우가 화면상 똑같이 보인다.

### 내 물량 (`partner-portal/pages/my-transactions/my-transactions.page.ts`)

시작일/종료일 필터, 무한스크롤, "출고명세서 다운로드" 버튼. 거래처 선택 UI가 없다
— 서버가 항상 로그인 사용자의 `partnerId`로 강제 스코프하므로 선택 UI 자체가
무의미하기 때문이다(`my-transactions.page.ts:13-16` 주석).

### 내 정산서 (`partner-portal/pages/my-statement/my-statement.page.ts`)

월 선택 → 조회. 운송료 항목(breakdown 링크 포함) + 보관료 합계 + 총계 + 엑셀
다운로드. 거래처 select 없음(위와 동일한 이유).
