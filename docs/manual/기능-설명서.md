# 물류 ERP 기능 설명서

본 문서는 이 저장소의 실제 소스 코드를 근거로 작성한 기능 설명서다. 화면 캡처가 아닌
코드(`apps/api`, `apps/web`, `prisma/schema.prisma`)를 직접 읽고 검증했으며, 모든 계산
규칙과 에러 코드는 `파일:라인` 형식으로 근거를 밝힌다. 코드로 확인하지 못한 부분은
추측하지 않고 `확인 필요`로 표시했다.

대상 범위: 마스터데이터(카테고리·거래처·품목·차량단가표) · 창고 입출고 실적 ·
정산 요금 계산(운송료·보관료) · 거래처 포털. `docs/prd/2026-07-26-erp-benchmark-prd.md`에
있는 향후 계획 항목은 미구현 상태이며 본 문서에서는 구현된 것으로 서술하지 않는다.

## 표기 규칙

- 코드 인용은 `apps/api/src/.../파일명.ts:라인번호` 형식을 쓴다.
- 문서체(`~한다/~이다`)로 서술한다.
- `확인 필요`로 표시된 항목은 소스에서 직접 확인하지 못했거나 코드 간 상충이 있는 부분이다.
